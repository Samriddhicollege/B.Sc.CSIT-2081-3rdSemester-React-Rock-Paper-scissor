## 📌 Project Overview

This is a web-based Rock Paper Scissors game developed using React. Players can compete against the computer, with real-time score tracking and persistent game state using **localStorage**. The application features a clean, responsive UI and intuitive gameplay mechanics.

---

## 🎯 Objectives

* Build a functional React application with state management
* Implement game logic and win/loss determination
* Create a responsive and user-friendly interface
* Persist game data using browser localStorage
* Practice component-based architecture

---

## 🛠️ Technologies Used

* **React.js** – UI framework
* **JavaScript (ES6+)** – Core logic
* **HTML & CSS** – Markup and styling
* **Local Storage API** – Data persistence

## ✨ Key Features

* ✅ Play Rock, Paper, or Scissors against the computer
* ✅ Real-time score tracking
* ✅ Persistent score storage (survives page refresh)
* ✅ Custom username support
* ✅ Loading animation during computer's "thinking"
* ✅ Reset game functionality
* ✅ Input validation
* ✅ Responsive component-based design

## 🧩 Screens / Modules

* **Game Container** – Main game interface
* **Score Board** – Display player and computer scores
* **Choice Buttons** – Selection buttons for Rock, Paper, Scissors
* **Result Display** – Show game outcome and choices

## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone <your-repo-link>
   ```

2. Navigate to the project folder:

   ```bash
   cd scissors-paper-rock
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

👉 The application will open at: **http://localhost:3000**

## 🎮 How to Play

1. Enter your username (optional)
2. Click on **Rock**, **Paper**, or **Scissors**
3. Wait for the computer to make its choice
4. View the result and updated scores
5. Play again or reset the game

---

## 📜 Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choices result in a Draw
